# QR Code Generator

A responsive QR Code Generator built using HTML, CSS, and JavaScript. This application allows users to generate QR codes instantly from text, URLs, or other input.

## Features

* Generate QR codes in real-time
* Convert text and URLs into scannable QR codes
* Clean and responsive user interface
* Fast and lightweight implementation
* Beginner-friendly project structure

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* QR Code API

## How to Run

1. Clone the repository
2. Open `index.html` in your browser
3. Enter text or a URL
4. Click **Generate QR**
5. Scan or save the generated QR code
